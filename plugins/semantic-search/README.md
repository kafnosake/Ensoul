# 语义搜索

EmbeddingGemma 2 本地多模态扩展。设置中的「语义搜索」位于「MCP 服务」下方，提供总开关、各类内容范围，以及助手检索、比较、分类、分组和自动索引开关。

首次使用：设置 → 更多 → EmbeddingGemma 2，点击「一键配置」自动准备 Python、CPU/CUDA 依赖和模型并验证；然后回到「语义搜索」开启 → 更新索引 → 打开搜索面板。设备和向量维度通过下拉选择即时保存，重新打开或重挂插件会保留。模型下载和环境安装只由显式操作触发，已有缓存会复用；关闭总开关会停止任务并释放模型。Python、模型与代理细项收在「高级设置」。

模型和独立运行环境保存在 ensoul 用户数据目录的 `env/semantic-search/`，所有工作区共用；专用解释器会出现在「Python 解释器管理」中，不更改当前激活项。旧工作区中的模型缓存首次配置时复制复用。插件源码不包含模型本体，复制源码后通过上述下载入口准备。

找做法沿用 `skills/find-recipe`：`recipe_search` 默认只查角色卡经验和 `work/` 文档，按需加入历史；最多 3 条、正文合计 3000 字符，结果保留来源与截断标记。模型不可用时仍走关键词与历史检索工具，不自动安装或全量加载库存。

使用说明、数据范围、存储作用域和验证入口见 [docs/semantic-search.md](../../docs/semantic-search.md)。
