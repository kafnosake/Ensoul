# 研发工程技能套件 (Dev Suite)

本套件聚合了项目研发与架构维护相关的 SOP 规范：

## 包含的细分子技能
1. **dev/refactor-safe** (安全重构规范)：小步快跑、局部替换、保留原格式行尾，避免大面积破坏。
2. **troubleshoot** (全局排障)：排查构建失败、界面不刷新、跨进程通信丢包。
3. **make-plugin** (插件开发)：开发独立插件、面板与命令响应三件套。

## 通用原则
- 优先局部精确修改，严禁无必要全文件重写。
- 改动 shared / main 需重新构建与重启；改动 renderer 仅需重新构建界面。
