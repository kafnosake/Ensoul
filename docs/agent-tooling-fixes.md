# Agent 工具反馈修复

2026-10-06。修复范围是调查中已复现的反馈失真与证据丢失；保留已有工具名、插件体系和任务执行路径。

## 行为变化

- `runtime-probe` 读取真实 `result` / `ctx` / `toolCallId`，宿主补充执行 `status` 与实际 `durationMs`。没有错误记录只表示当前未捕获，不再宣称运行健康。卸载移除两个进程监听，清空旧工作区缓冲；恢复 console 时保留其他包装者。
- `code_slice` 用现有 TypeScript 解析器定位 JS/TS 声明，精确匹配符号名。字符串、注释、模板与正则中的括号不会截断范围；超过 200 行或无法解析时明确说明。
- `review_changes` 用无 shell 的 Git argv 调用，路径置于 `--` 后；扫描未跟踪文件、暂存区与工作区，兼容首次提交前的仓库。空范围、二进制跳过、Git 失败单独报告。规则结果是审查线索，不作为代码安全证明。
- 排查账本通过 `api.state` 保存，按 `panelId` 与 `taskId` 分槽；没有任务编号时使用该面板的会话槽。同一假设可更新，testing 不作为已确认事实；提示和压缩快照仅提供当前槽的记录。保存失败与取消不报告成功。
- AGENTS.md / CLAUDE.md 每轮提供当前正文，未变时复用读取结果。热提示每轮提供最后一版完整规则，直到压缩或清理后固化到基底；恢复旧基底也按有效版本比较。
- 命令输出交给统一落盘流程前不再截断；非零退出成为真实工具失败，完整输出包含退出码。历史记录超过 1200 字时保留完整产物及可展开引用；压缩输入包含真实工具参数、结果和引用。

`symbol_find` 仍是文本候选检索，不是跨文件语言服务。运行探针当前覆盖主进程与工具钩子，没有在本批接入 renderer、网络或 IPC 全链路诊断。

## 状态与兼容

新版账本保存到 `.ensoul/state/code-intelligence.json`，格式为 `schemaVersion: 1` 与 `panels[panelId][taskScope]`。

旧 `.ensoul/state/investigation.json` 保留。首次保存时将旧内容带入 `legacyRecords`，不将无归属记录猜测分配给当前面板或任务，也不自动注入这些记录。旧文件及未提交的源码不被清理。

工具完成钩子新增两个可选字段，旧插件仍能接收原有字段。运行探针对旧宿主的失败字符串也能做有限识别，实际耗时未报告时不填假值。
