# 本地化（中 → 英）工作契约

> 这份文档是**翻译的人、改代码的人、验收的人**共用的唯一说明。开工前读它，别问别人。

## 一句话机制

**中文原文就是词典的 key。** 代码里写 `t('通用设置')`：中文下原样返回，英文下查词典。
词典里没有的，回落成中文 —— 所以翻一半也能上线，缺的那句顶多是中文，不会白屏、不会报错。

```ts
t('通用设置')            // 中文 → 通用设置   ／ 英文 → General
t('已派给 {who}', { who: '张三' })   // 占位符用 {名字} 写，只在英文串里替换
```

词典有两处：

| 文件 | 装什么 | 谁维护 |
|---|---|---|
| `src/shared/i18n.ts` 的 `EN` | 短文案：按钮、标题、提示、错误 | 我（翻译只管交 JSON） |
| `src/shared/i18n.prompts.ts` 的 `EN_PROMPTS` | 长文本：系统提示、插件里写给模型的规矩 | 同上 |

## 翻译的人要做的（**不碰代码**）

1. 打开 `work/i18n/<批次>.json`，每条长这样：

```json
{ "zh": "通用设置", "len": 4, "where": ["src/renderer/...:57"], "en": "" }
```

2. **只填 `en`**，其余字段一个字都别动（`zh` 是 key，改一个字节就查不到了）。
3. 填完存到 `work/i18n/done/<批次>.json`，在对话里说一声「<批次> 好了」。合并进词典由我执行。

`len` 是这条中文有几个字，用来估长短 —— 英文一般比中文长 1.5~2 倍（按钮位置会因此变宽），
界面上放不下的那几条我在合并时会顺手看一遍。

## 语气与格式

- **命令就是命令**：原文「不要自己动手」→ `Do not act on your own.`，不要翻成 `You might want to avoid…`。
- **中文的长句拆成两句英文**可以；反过来不许把两句并成一句。
- 标点用英文标点（`,` `.` `:`），**中文的 `·` 保留**（它是列表符号，两边都认）。
- 中文的 `——`（破折号）在英文里写成 ` — `（前后带空格）。
- 代码、路径、工具名、字段名、`{{占位符}}`、`<标签>` **原样搬**，一个字符都不改。
- 引号里的中文示例（`如 src/pay/、config/pay.json`）要把说明文字翻掉，示例本身保留。
- 界面按钮**尽量短**（一个词最好）：`确定`→`OK`，`取消`→`Cancel`，`新建`→`New`。
- 句首大写，句尾不加句号（界面短句）；完整句子照常加标点。

## 提示词那批的三条硬规矩（翻错了模型会乱来，比不翻更糟）

1. **只译措辞，不动结构**：编号、分隔线、`【】`标记、小节层级、空行都照旧。
2. **样例原样搬**：`t('确定')` 这种代码片段、JSON 字段名、工具名、路径一个字不改。
3. **不加不减**：原文没说的不要补（别自作主张加一句解释），说了的不许省略。

## 改代码的人要做的（**另一批人**）

把界面里的中文套上 `t()`。三种改法：

```tsx
// 1. 字符串字面量
const title = t('通用设置');
// 2. JSX 文本
<div>{t('主题')}</div>
// 3. JSX 属性
<button title={t('设置')} />
```

三处**不要**套：
- 不是给人看的：`console.log`、给模型的结构化字段名、CSS 类名、事件名；
- `case '中文':` 这种**当值用的字符串**（它是逻辑的一部分，套了就断）；
- 对象字面量的 **key** 位置（`{ '中文': 1 }` 里的那个）—— 要套的是它的**值**。

改完必须 `npm run build:renderer` 过一遍（那个白屏守卫会拦下「用了但没定义的名字」）。


## 插件怎么取词（**跟核心不一样，先看这一段再动手**）

插件面板（`plugins/<名>/panel.tsx`）与插件主进程（`plugins/<名>/index.js`）都**不 import 核心的文件** ——
它们是外来的脸，不该知道核心内部文件在哪。核心把取词函数挂到全局一次，插件只管取：

```tsx
// 插件面板：window 上取
const i18n = (window as any).__ensoulI18n;
const tr = i18n ? i18n.t : (s: string) => s;   // 拿不到就回落原文（跟中文下的表现一致）
```

```js
// 插件主进程：global 上取
// 注意：不要写在模块顶层缓存 —— 语言可能在插件加载之后才定下来，写在函数体里现取
function say() {
  const i18n = global.__ensoulI18n;
  return i18n ? i18n.t('中文原文') : '中文原文';
}
```

两条纪律：

1. 插件面板里的**组件**要用 `useLang()` 订阅（从核心拿不到就直接听 `window.__ensoulI18n.onLang`），
   否则切语言时只有核心界面在变、插件面板停在旧语言上。
2. 插件声明的 `panel: { label, hint }` 由核心按语言翻译（见 main/plugins.ts），**插件自己不用管**。
